# การเชื่อมแบบจำลองระนาบ ดิฟเฟอเรนเชียล และการถ่ายน้ำหนัก V1

ต้นฉบับภาษาอังกฤษ: `COUPLED_PLANAR_DIFFERENTIAL_LOAD_TRANSFER_V1.md`

## ขอบเขตคำกล่าวอ้าง

Work 071 เป็นการทดลองเชื่อมระบบสังเคราะห์ระดับ Level 0 แบบ deterministic เพื่อตรวจว่า geometry แบบสามจุดสัมผัสจาก Work 069 และดิฟเฟอเรนเชียลล้ออิสระจาก Work 070 สามารถแลกเปลี่ยนแรงตามยาว แรงด้านข้าง โมเมนต์ yaw ความเร็วล้อ แรงกดปกติ และพลังงานได้โดยไม่ละเมิด interface ที่ประกาศไว้ งานนี้ไม่ใช่การยืนยันทางกายภาพ ไม่ใช่แบบจำลองช่วงล่างแบบ transient และไม่ใช่หลักฐานว่ารถพร้อมแข่งขัน

## แบบจำลองและการตั้งต้นพลังงาน

ใช้ architecture v3 จาก Work 069 โดยไม่เปลี่ยน geometry (`cf78a1c499790aed6c8b117c8f583a427a9d91a9fb36605e2b7038b2907b1418`) จุดสัมผัสหน้าสองจุดขับเคลื่อนและเลี้ยว ส่วนจุดรองรับหลังเป็นแบบ passive ก่อนรันต้องตรวจความสอดคล้องของมวล จุดศูนย์กลางมวล yaw inertia ตำแหน่งจุดสัมผัส รัศมีล้อ ขีดจำกัดชิ้นส่วน และขีดจำกัดมุมเลี้ยวที่ได้จาก geometry

ที่จุดสัมผัส `i` ความเร็วในกรอบตัวรถถูกแปลงไปยังกรอบของล้อที่เลี้ยวอยู่ wheel slip ตามยาวและ slip angle ด้านข้างสร้างแรงร้องขอ แล้ว friction ellipse จะฉายแรงทั้งสองพร้อมกันลงบนขีดความสามารถที่ขึ้นกับแรงกดปกติ การแก้ fixed-point จะปรับแรงกดปกติแบบ quasi-static จากความเร่งตามยาวและด้านข้างของ step เดียวกัน:

```text
sum(N_i)       = m g
sum(x_i N_i)   = -m a_x h
sum(y_i N_i)   = -m a_y h
omega_L        = omega_c - delta_omega
omega_R        = omega_c + delta_omega
J_delta d(delta_omega)/dt = q_L - q_R - c_delta delta_omega
```

แรงกดปกติค่าลบจะไม่ถูกตัดเป็นศูนย์ แต่จะสร้างสถานะปลายทาง `contact_lift` และ `DNF` จุดสัมผัสหลังส่งแรงด้านข้างได้ แต่ห้ามสร้างแรงบิดขับเคลื่อน

ความเร็วรถเริ่มต้นคือ `10 m/s` โดยจับคู่ความเร็วล้อ carrier และ converter ตามจลนศาสตร์ พลังงานจลน์ของตัวรถและชุดหมุนถูกหักออกจากงบ storage ที่ประกาศไว้ `50,000,000 J` ทำให้พลังงานรวมที่นับได้ตอนเริ่มต้นเท่ากับ `50,000,000 J` พอดี และพลังงานฝั่ง powertrain ที่นับได้หลังแบ่งงบเหลือ `49,986,155.22844996 J`

## การออกแบบการทดลอง

- ตัวแปรอิสระ: เครื่องหมายและขนาดมุมเลี้ยว friction ซ้าย/ขวา throttle ขนาด time step สถานะดิฟเฟอเรนเชียล และการถ่ายน้ำหนักตามความเร่ง
- ตัวแปรตาม: วิถี ความเร็วตัวรถ yaw ความเร็วแต่ละ branch โหมดดิฟเฟอเรนเชียล แรงกด/แรง/การใช้ขีดจำกัดของสามจุดสัมผัส saturation ความร้อน งาน residual ดุลแรง residual พลังงาน สถานะปลายทาง และ replay identity
- ตัวควบคุม: เลี้ยวศูนย์ เลี้ยวบวก/ลบแบบ mirror, split-grip/spatial mirror, มุมเลี้ยวเกินขีดความเป็นไปได้, exact replay และ half-step refinement
- สมมติฐานที่ต้องการทดสอบ: คำสั่งที่รับได้ต้องเชื่อมแรงและอนุรักษ์พลังงาน ตัวควบคุมสมมาตรและ mirror ต้องรักษา invariant และคำสั่งที่เป็นไปไม่ได้ต้องล้มเหลวอย่างสังเกตได้
- เงื่อนไขหักล้าง: ซ่อนการตัดแรงกด ล้อหลังสร้างแรงขับ เครื่องหมาย yaw ผิด mirror ไม่ตรง carrier average ผิด contact utilization เกิน tolerance ไม่มีการนับ heat/work เผยแพร่สถานะที่ solver ไม่ converge residual มากเกินกำหนด หรือ replay/refinement ไม่ผ่าน

reference ใช้มุมเลี้ยว `+0.01 rad`, throttle `0.3`, ระยะเวลา `0.5 s` และ time step `0.001 s` ตัวควบคุมความล้มเหลวใช้มุมเลี้ยว `+0.04 rad` ส่วน split grip ใช้ friction ตามยาวซ้าย/ขวา `1.0/1.2`

## ผลการทดลอง

reference จบครบ 500 steps ตำแหน่งสุดท้าย `(x, y) = (5.3705046591, 0.1338516706) m`, heading `0.0977737591 rad`, yaw rate `0.3638034160 rad/s` และความเร็วตัวรถ `(u, v) = (11.4022671884, -0.3456498170) m/s` ความเร็ว branch อิสระคือซ้าย `95.1693758072 rad/s` และขวา `83.5724925848 rad/s` แรงกดปกติต่ำสุด `282.9427858151 N` การใช้ขีดจำกัดแรงรวมสูงสุด `1.0000000000000002` และมี 302 steps ที่รายงาน saturation แทนการซ่อนแรงร้องขอที่เกินขีดจำกัด

ตัวควบคุมมุมเลี้ยวศูนย์รักษาตำแหน่งด้านข้าง heading ความเร็วด้านข้าง yaw rate และความเร็วโหมดดิฟเฟอเรนเชียลเป็นศูนย์พอดี การเลี้ยวเครื่องหมายตรงข้าม mirror สถานะมีเครื่องหมายที่เลือกทั้งหมดโดยมี absolute mismatch ที่บันทึกไว้เป็นศูนย์ split grip ให้ความเร็ว branch `98.9391511463/82.1868161465 rad/s`; เมื่อสลับ grip และเครื่องหมายมุมเลี้ยว ความเร็ว branch สลับกันและสถานะด้านข้าง/yaw mirror กันโดย mismatch เป็นศูนย์

ตัวควบคุมหักล้าง `+0.04 rad` ไม่ผ่านเป็นการเคลื่อนที่ที่เป็นไปได้ ที่ attempted step 443 solver ได้แรงกดปกติต่ำสุด `-0.1415633491 N` การรันจบที่ `0.442 s` ด้วย `DNF: contact_lift` และเก็บค่าลบไว้เป็นหลักฐาน

## การตีความและข้อจำกัด

หลักฐานสนับสนุนเพียงคำกล่าวอ้างแคบว่าแรงและพลังงานสามารถไหลผ่าน geometry ยาง ดิฟเฟอเรนเชียล powertrain และ rigid body ระนาบได้ใน transaction แบบ Level 0 ที่ deterministic ผลนี้ขัดกับสมมติฐานว่าล้อทั้งสองต้องมีความเร็วเท่ากันเสมอ และแสดงขอบเขตความเป็นไปได้ทางฟิสิกส์ผ่าน contact lift ที่ชัดเจน

ยังมีคำอธิบายทางเลือก: residual ที่ดีอาจเกิดจากสมการภายในที่สอดคล้องกันโดยยังไม่แทนยางหรือช่วงล่างจริง ค่าสัมประสิทธิ์เป็นค่าจำลอง การถ่ายน้ำหนักเป็น quasi-static และยางยังไม่มี relaxation, temperature, wear, camber, aligning moment หรือข้อมูลวัดจริง ยังไม่มีระยะยุบ spring/damper, roll-centre geometry, unsprung mass, wheel hop, aero map, road roughness, path controller, ขอบสนาม, lap timing หรือการเทียบกับการทดลองจริง ความเชื่อมั่นสูงเฉพาะการเชื่อม software แบบ deterministic และต่ำต่อความแม่นยำทำนายโลกจริง

คำกล่าวอ้างขั้นถัดไปควรบังคับให้มีสถานะล้อ/ช่วงล่างแบบ transient แล้วจึงทดสอบ path/circuit แบบ closed-loop โดยคง gate ด้านพลังงาน จุดสัมผัส ความล้มเหลว และ replay ชุดเดิม

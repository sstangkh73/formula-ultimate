# การเชื่อมโยงมวลสปริง ผิวถนน และแนวดิ่งของยาง V1

แปลจากไฟล์ภาษาอังกฤษ: `SPRUNG_BODY_ROAD_TYRE_VERTICAL_V1.md`

## ขอบเขตของข้อกล่าวอ้าง

Work 073 เป็นหลักฐานสังเคราะห์ระดับ Level 0 แบบ deterministic ว่าสถาปัตยกรรม Work 069 v3 ปัจจุบันสามารถส่งแรงแนวดิ่งผ่านมวลสปริง ชุดสปริง/แดมเปอร์ มวลใต้สปริง ยางที่ยุบตัวได้ และขอบเขตถนนที่เคลื่อนที่ พร้อมเชื่อมกับแรงยางแนวราบของ Work 071 ได้ นี่ยังไม่ใช่การระบุพารามิเตอร์จากการวัด การตรวจสอบทางกายภาพ หรือหลักฐานว่ารถพร้อมแข่ง

## แบบจำลองฟิสิกส์

สถาปัตยกรรมที่ materialize แล้วเป็นแหล่งมวลและโมเมนต์ความเฉื่อยที่จุดศูนย์กลางของชิ้นส่วน ชิ้นส่วนสัมผัสพื้นยังใช้มวลใต้สปริงเชิงผลจาก Work 072 ชิ้นส่วนอื่นทั้งหมดรวมเป็นมวลสปริงและความเฉื่อย roll/pitch ด้วยความเฉื่อยของ primitive และทฤษฎีแกนขนาน ค่าที่คำนวณได้คือ:

- มวลสปริง `245.95200000000003 kg`;
- ความเฉื่อย roll `4.218672483307425 kg m2`;
- ความเฉื่อย pitch `46.253188363933454 kg m2`.

การกระจัดวัดจากสมดุลสถิตและทิศขึ้นเป็นบวก สำหรับจุดสัมผัส `i` ที่ `(x_i, y_i)`:

```text
q = [z_s, theta, phi, z_u1, z_u2, z_u3]
z_body_i = z_s - x_i theta + y_i phi
s_i = z_ui - z_body_i
t_i = z_road_i - z_ui
F_s,i = k_s,i s_i + c_s,i s_dot_i
F_t,i = k_t,i t_i + c_t,i t_dot_i
N_actual,i = N_static,i + F_t,i
M q_ddot + C q_dot + K q = f_inertial + f_road.
```

ระบบเชิงเส้น 6 DOF เดินเวลาด้วย implicit midpoint Work 071 สร้างโมเมนต์เฉื่อยตามยาว/ด้านข้างจากรอบคำนวณ acceleration/load ปัจจุบัน จากนั้น Work 073 ส่ง `N_actual` กลับภายใน fixed point เดียวกัน ดังนั้น combined-force ellipse ใช้โหลดที่แก้จากสมการยางจริง ไม่ใช่ quasi-static target

จุดสัมผัสขับเคลื่อนใช้ `k_t = 180,000 N/m`; จุดสัมผัส passive ใช้ `120,000 N/m` อัตราส่วน damping แนวดิ่งของยางทุกจุดคือ `0.15` ค่าเหล่านี้เป็นพารามิเตอร์สังเคราะห์ที่ประกาศไว้ ไม่ใช่ค่าจากการวัด

## กฎอนุรักษ์และความล้มเหลว

พลังงานแนวดิ่งรวมพลังงานจลน์ของมวลสปริง/ใต้สปริงและพลังงานสปริงของช่วงล่าง/ยาง ความร้อนจากแดมเปอร์ทั้งสอง งานเฉื่อย และงานถนนแบบมีเครื่องหมายถูกแยกกัน:

```text
R_vertical = delta(E_vertical) + Q_suspension + Q_tyre
             - W_inertial - W_road.
```

พลังงานแนวดิ่งเริ่มต้นถูกหักจากงบสะสมคงที่ `50,000,000 J` โหลดตั้งฉากจริงที่ไม่เป็นบวกให้ `DNF: contact_loss` แบบไม่ commit; ระยะช่วงล่างเกิน `0.05 m` ให้ `DNF: suspension_travel` ที่ boundary step ซึ่ง commit แล้ว ไม่มีการ clip โหลดหรือระยะ สถานะ singular, non-finite, ไม่ลู่เข้า หรือ residual เกินเกณฑ์ถือเป็น invalid

## การทดลองที่ลงทะเบียนล่วงหน้า

- ตัวแปรอิสระ: เครื่องหมายมุมเลี้ยว จุด/แอมพลิจูด/เวลา/รูปร่างถนน stiffness/damping ของยาง time step และสถานะแนวดิ่งเริ่มต้น
- ตัวแปรตาม: heave/pitch/roll การเคลื่อนที่ใต้สปริง ระยะและแรงของช่วงล่าง/ยาง โหลดตั้งฉากจริง สถานะ planar/yaw บัญชีความร้อน/งาน/พลังงาน residual ของสมการ เหตุหยุด และ hash
- ตัวควบคุม: Work 072 ไม่เปลี่ยน exact replay, zero steer, opposite steer, bump ซ้าย/ขวาแบบ mirror, damping ยางเป็นศูนย์, stiffness ยางครึ่งหนึ่ง, road drop, road ramp ขนาดใหญ่, initial-state travel และ time step ครึ่งหนึ่ง
- เกณฑ์ล้มเหลว: hash ต้นทางเปลี่ยน การข้าม actual load ตัวตน contact ไม่ตรง พลังงานอธิบายไม่ได้ mirror เกิน `1e-9`, refinement เกิน `2%`, clip ที่ซ่อนอยู่ เหตุหยุดผิด หรือ test ใดล้มเหลว

สมมติฐานหลักถูกตั้งให้หักล้างได้ด้วยตัวควบคุมเหล่านี้: การวิ่งปกติต้องกระตุ้น body mode ที่มีขนาดจำกัดโดยไม่เสีย contact และพารามิเตอร์ฟิสิกส์ที่เปลี่ยนต้องทำให้การตอบสนองเปลี่ยนอย่างสังเกตได้

## การตีความและหลักฐานที่ยังขาด

หลักฐานสนับสนุนแสดงเส้นทางเชิงเหตุจากการกระจัดของถนนและความเร่งแนวราบ ผ่าน geometry/mass/spring/damper แนวดิ่ง ไปสู่โหลดยางจริงและขีดจำกัดแรงแนวราบ ผล large-ramp ขัดกับสมมติฐานว่าระยะช่วงล่างต้องเป็นขีดจำกัดแรก คำอธิบายทางเลือกของความสอดคล้องเชิงตัวเลขคือความเป็นเชิงเส้นของแบบจำลองและการใช้ implementation ร่วมกันระหว่าง dynamics กับ ledger; control เชิง analytical/mirror/refinement ลดความเสี่ยงนี้แต่ไม่กำจัดทั้งหมด

หลักฐานที่ยังขาดคือ geometry ของ linkage และ motion ratio จาก CAD, bump stop, contact ยางไม่เชิงเส้น, road spectrum จากการวัด, parameter identification, chassis flexibility, anti-dive/squat, aerodynamic load, การหา event ภายใน sub-step, hardware test และการเทียบกับ solver ภายนอก ความเชื่อมั่นสูงว่าโค้ดทำตามสัญญาสมการที่ประกาศ แต่ความเชื่อมั่นต่ำว่าพารามิเตอร์ปัจจุบันทำนายรถจริงได้

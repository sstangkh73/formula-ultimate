# แบบจำลองฟิสิกส์สนามจริง Level 0

ไฟล์ต้นฉบับภาษาอังกฤษ: `CIRCUIT_MODEL.md`  
สถานะ: ใช้งานเป็น baseline สำหรับคัดกรองแล้ว  
แค็ตตาล็อก: `config/circuits/real_circuits_v1.json`

## จุดประสงค์

แบบจำลองสนามจะส่งข้อจำกัดจากโลกจริงให้เอเจนต์ก่อนเริ่มออกแบบรถ ทำให้วงจร
ออกแบบไม่สามารถมองสนามเป็นเพียงชื่อหรือเวลาเป้าหมาย แต่ละสนามให้ขนาดของเรซ
ข้อมูลสภาพแวดล้อมเมื่อมีหลักฐาน gate ความกว้างแบบตรวจสอบย้อนกลับได้ และเวกเตอร์
แรงกดดันต่อการออกแบบที่แตกต่างกัน

นี่คือการคัดกรองความเป็นไปได้ระดับ Level 0 ไม่ใช่แบบสำรวจสนาม และไม่สามารถ
ยืนยันว่ารถผ่านการตรวจสอบทางฟิสิกส์แล้ว

## การไหลของข้อมูล

```text
ข้อเท็จจริงจากแหล่งทางการ
        |
        v
CircuitProfile ------> เวกเตอร์แรงกดดันก่อนออกแบบ
        |
        +------------> gate ความกว้าง: passed / rejected / indeterminate
        |
        +------------> ระยะเรซ, residual จุดสตาร์ต, ความหนาแน่นอากาศ ISA
                              |
                              v
                    การสร้างรถและ simulation ภายหลัง
```

## หลักฐานสามชั้นที่แยกจากกัน

1. **ข้อเท็จจริงที่เผยแพร่:** ความยาวต่อรอบ จำนวนรอบ ระยะเรซทางการ จำนวนโค้ง
   ระดับความสูงอ้างอิง และความกว้างที่เผยแพร่เมื่อพบแหล่งทางการที่ใช้กับ layout
   นั้นได้ ค่าความกว้างทุกค่าผูกกับ source ID ที่ประกาศไว้
2. **อินพุตคัดกรองที่อนุมาน:** คะแนนแรงกดดัน 8 แกนและข้อความจุดแข็ง/จุดอ่อน
   คะแนนเหล่านี้เป็นสมมติฐานวิจัยที่สร้างจากคำอธิบายสนามทางการ ไม่ใช่แรงที่วัดได้
   หรือน้ำหนักสำหรับคำนวณเวลา
3. **เอาต์พุตที่สังเกตได้:** ความหนาแน่น ISA, residual ของระยะทางทางการ และผล
   ความกว้าง หลักฐานที่หายไปต้องแสดงเป็น `indeterminate`

แกนแรงกดดัน 8 แกนคือ `straight_speed`, `low_speed_agility`,
`high_speed_cornering`, `braking`, `traction`, `elevation`,
`thermal_cooling` และ `confinement` เวอร์ชัน 1 ใช้เฉพาะ
`0.00, 0.25, 0.50, 0.75, 1.00` เพื่อไม่สร้างความแม่นยำปลอม และเวกเตอร์ของทั้ง
10 สนามไม่ซ้ำกัน

## การคัดกรองความกว้างรถแบบสถิต

เมื่อความกว้างรถคือ \(w_v\) ระยะเผื่อต่อข้างคือ \(c\) และระยะเผื่อหลักฐานคือ
\(u\) ความกว้างทางผ่านที่จำเป็นคือ

\[
w_{required} = w_v + 2c + u.
\]

นำไปเทียบกับความกว้างสนามต่ำสุดที่เผยแพร่และใช้ได้
\(w_{published,min}\):

- `rejected` เมื่อ \(w_{required} > w_{published,min}\)
- `screen_passed` เมื่อ \(w_{required} \le w_{published,min}\)
- `indeterminate` เมื่อไม่มีหลักฐานความกว้างที่ใช้ได้

`screen_passed` หมายถึงเพียงกรอบสี่เหลี่ยมสถิตไม่กว้างกว่าค่าต่ำสุดที่เผยแพร่
ไม่ได้ยืนยันว่ารถเลี้ยวผ่านโค้งได้ ระยะฐานล้อ มุมเลี้ยว ขอบเขตยาง ส่วนยื่นตัวถัง
ตำแหน่งกำแพง kerb, banking, pitch/roll และ swept path ทั้งหมดต้องใช้ corridor 3D
จากการสำรวจในงานระดับถัดไป

คำสั่งตัวอย่าง:

```powershell
python scripts/validate_circuits.py --vehicle-width-m 7.0 --clearance-per-side-m 0.25
```

ด้วยหลักฐานปัจจุบัน รถนี้ถูก Monaco ปฏิเสธ ผ่านเฉพาะ static screen ที่ Monza,
Suzuka และ Sao Paulo และอีก 6 สนามเป็น `indeterminate` เอเจนต์ห้ามตีความ
`indeterminate` ว่าอนุญาตให้แข่ง

## การคัดกรองบรรยากาศ

เมื่อมีระดับความสูงอ้างอิงพร้อมแหล่งข้อมูล ระบบคำนวณความหนาแน่นอากาศแห้งใน
ชั้น troposphere ของ International Standard Atmosphere:

\[
T = T_0-Lh,
\qquad
p = p_0\left(\frac{T}{T_0}\right)^{g_0/(RL)},
\qquad
\rho = \frac{p}{RT}.
\]

ค่าคงที่หน่วย SI คือ \(T_0=288.15\ K\), \(p_0=101325\ Pa\),
\(L=0.0065\ K/m\), \(g_0=9.80665\ m/s^2\) และ
\(R=287.05287\ J/(kg\,K)\) ที่ระดับความสูง `2,285 m` ของ Mexico City ระบบให้
ค่าประมาณ `0.978 kg/m^3` ส่วนระดับน้ำทะเลให้ประมาณ `1.225 kg/m^3`

ค่านี้เป็นบรรยากาศอ้างอิง ไม่ใช่สภาพอากาศของวันแข่ง และต้องไม่แทนค่าความดัน
อุณหภูมิ ความชื้น ลม หรืออุณหภูมิผิวสนามที่วัดได้โดยเงียบ ๆ

## Residual ของระยะเรซ

แค็ตตาล็อกเก็บทั้งระยะเรซทางการและ `lap_length_m * race_laps` ผลต่างถูกแสดงเป็น
`race_start_offset_m` และไม่ถูกแก้ทิ้ง เพราะความยาวรอบที่เผยแพร่มีการปัดเศษ และ
เส้นสตาร์ตอาจไม่ตรงกับเส้นชัย ตัวอย่างเช่น Monza แสดง `-309 m`

## ขอบเขตหลักฐานปัจจุบัน

- มีสนามจริง 10 สนาม: Monaco, Monza, Spa-Francorchamps, Singapore, Suzuka,
  Silverstone, Hungaroring, Mexico City, Bahrain และ Sao Paulo
- ปัจจุบันมีหลักฐานความกว้างทางการที่ใช้กับ profile ได้ 4 สนาม: Monaco, Monza,
  Suzuka และ Sao Paulo
- ผู้จัด Singapore เผยแพร่ `10-15 m` สำหรับ layout ปี 2008 ที่เลิกใช้แล้ว จึงเก็บ
  ไว้อธิบายว่าทำไมความกว้างปัจจุบันยังไม่ทราบ แต่ไม่ใช้เป็น hard limit ปัจจุบัน
- ผู้ดำเนินการ Bahrain เผยแพร่ `14-15 m` สำหรับ Inner Track ไม่ใช่ Grand Prix
  Track จึงเก็บเป็นหลักฐานที่ใช้ไม่ได้กับ layout นี้ และ Bahrain ยังเป็น
  `indeterminate`
- เวอร์ชันนี้มีเพียง Mexico City ที่มีระดับความสูงเชิงตัวเลขพร้อมแหล่งอ้างอิง
- ยังไม่มี grip, ความขรุขระ, camber, banking, gradient ตามตำแหน่ง, รูปร่างกำแพง,
  kerb, การกระจายสภาพอากาศ, geometry ของ pit และ centerline/corridor 3D
- จุดแข็ง/จุดอ่อนและคะแนนแรงกดดันเป็นสมมติฐานสำหรับการเปรียบเทียบแบบควบคุม
  ต้องทำ sensitivity analysis และพยายามหักล้างด้วย telemetry หรือ simulation
  ที่ละเอียดกว่า

## ระดับการตรวจสอบถัดไป

งานสนามถัดไปควรนำเข้า centerline และขอบซ้าย/ขวา 3D ที่มีเวอร์ชัน บันทึกระบบพิกัด
และความไม่แน่นอนของการสำรวจ แล้วนำ envelope รถทั้งคันไปทดสอบการชนแบบ
swept-volume ขั้นนั้นจึงจะเปลี่ยนความยาวรถ ระยะฐานล้อ geometry การเลี้ยว ส่วนยื่น
และรูปทรงตัวถังให้เป็น hard constraint เฉพาะสนามได้ แทนการเป็นเพียงคำเตือน

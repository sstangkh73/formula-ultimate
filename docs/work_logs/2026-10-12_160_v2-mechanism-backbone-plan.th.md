## วัตถุประสงค์

เริ่มงาน Tier B ด้วยชั้นกลไก (mechanism layer) ที่วางแผนหลังจากกลุ่มชิ้นส่วน v1
ถูกสร้างและวัดแล้ว งานนี้เพิ่มโครงของชั้นกลไกและสมาชิกตัวแรก คือแผ่นพื้นโครงสร้าง
(`load_structure`) ใต้กลุ่มชิ้นส่วนที่วัดได้ ต่อกับ leaf ที่ต่ำที่สุดของกลุ่ม งานถัดไป
จะติดล้อ เบรก การบังคับเลี้ยว การส่งกำลัง ตัวแปลงพลังงาน ภาชนะ ตัวควบคุม และพื้นผิว
ระบายความร้อนเข้ากับแผ่นพื้นนี้

## การออกแบบ (ตัดสินใจที่นี่ บันทึกไว้ให้งานถัดไป)

- กลุ่มชิ้นส่วน v1 (decomposition, layout, bore, fastener) ไม่เปลี่ยน หลังเขียนเมชแล้ว
  ตัวสร้างอ่านเมชกลับมาวัดกล่อง `[X0,X1] x [Y0,Y1] x [Z0,Z1]` และ leaf ที่ต่ำที่สุด
- leaf ของกลไกอยู่ใน assembly ระดับรากใหม่ `m<k>-<capability>` ที่ติดแท็ก
  capability ของมัน ชิ้นส่วนหลักฐานทุกชิ้นจึงอยู่ใน subtree ที่ติดแท็ก และต่อกับกลุ่ม v1
  ผ่านแผ่นพื้นเท่านั้น
- แผ่นพื้น: แผ่นแปดเหลี่ยมตัดมุม ผิวบนอยู่ที่ `Z0` รอยเท้า = รอยเท้ากลุ่มชิ้นส่วนบวก
  ระยะขอบที่สุ่มจาก seed บวกช่องว่างสำรองด้าน +x สำหรับโมดูลภายหลัง บวกขอบยื่นสำหรับ
  แนวล้อในอนาคต ความหนา ระยะขอบ การตัดมุม และความยาวช่องสำรองสุ่มจาก seed
  interface `bonded` ระหว่างแผ่นพื้นกับ leaf ต่ำสุด (leaf นั้นมีจุดยอดที่ `Z0`
  เหนือผิวบนของแผ่นพื้น)
- ไวยากรณ์ leaf ของกลไก `func-leaf-mechanism-v2`: `section` รูปหลายเหลี่ยม
  (ลูปนอกและลูปรูได้) -> `extrude` ตรงตามแกน +z เฉพาะที่ -> `transform` แบบแข็งเกร็ง
  มีแต่หน้าแบน การสัมผัสและระยะเผื่อจึงแม่นยำหลังการแบ่งสามเหลี่ยม
- manifest ที่รวมแล้วต่อชิ้นส่วนและ assembly ของกลไกใต้ราก แล้วคำนวณมวลและจุด
  ศูนย์กลางมวลของทุก assembly ใหม่ด้วยเลขคณิตเดียวกับ `part_tree.roll_up`
  interface ชนิด v2 (`bearing`, `guide`, `rolling`) ต่อที่ระดับ manifest นอกตัวตรวจ
  `PartTree` ของ v1
- หลักฐานออกเฉพาะ capability ที่ทำเสร็จ งานนี้ออก `load_structure: {members: [deck]}`
  B1-B9 ของชุดยอมรับจะผ่านไม่ได้จนกว่าจะครบเก้า (ชุดทดสอบตรวจชุดคีย์ก่อน)

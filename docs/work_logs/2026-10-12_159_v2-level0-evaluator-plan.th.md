## สมมติฐานทางฟิสิกส์ (SI)

- มวล: `mass_kg` ของโหนดรากใน manifest โดยไม่แก้ไข (มวลรวมแบบจุด)
- พื้นที่ลาก: `C_box * extent_y * extent_z`, `C_box = 1.0` โดยขนาดมาจากจุดยอดของ
  เมช leaf ทั้งหมด เป็นขอบเขต ไม่ใช่ค่าลากที่คำนวณได้ (สัญญาอนุญาต
  `0 < A <= 1.5 * extent_y * extent_z`)
- สัมประสิทธิ์ความต้านทานการหมุน 0.015 ความหนาแน่นอากาศจากสนาม (ISA) หรือ
  1.225 kg/m^3 แรงโน้มถ่วง 9.80665 m/s^2 ความชันศูนย์
- แรงขับคงที่ 4000 N พลังงานบนรถ 4.0e9 J (มากกว่า `F * ระยะแข่ง`) ไม่มีความร้อน
  ทิ้งหรือกำลังเสริม แบบจำลองความร้อนจึงอยู่ที่อุณหภูมิแวดล้อม สนาม `monza_2026`
  จาก `config/circuits/real_circuits_v1.json`
- ก้าวเวลา 1 s, timeout 36000 s, bisection 64 รอบ, seed 0

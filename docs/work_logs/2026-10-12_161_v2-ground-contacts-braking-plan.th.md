# แผนงาน Work 161: จุดสัมผัสพื้นของ v2 พร้อมโรเตอร์และสเตเตอร์เบรก

ต้นฉบับภาษาอังกฤษ: `2026-10-12_161_v2-ground-contacts-braking-plan.md`

สถานะ: Completed

## วัตถุประสงค์

เพิ่มมุมสัมผัสพื้นที่หมุนได้สี่มุมในชั้นกลไก v2 โดยแขวนกับแผ่นพื้นของ Work 160
เพื่อให้แพ็กเกจมีหลักฐาน `ground_propulsion` และ `braking` จริง: การเคลื่อนที่แบบ
revolute หมุนครบรอบพร้อม interface `bearing` มีเพียงจุดสัมผัสที่หมุนได้อยู่ในแถบพื้น
จุดศูนย์กลางมวลอยู่ภายในรูปหลายเหลี่ยมรองรับ และสเตเตอร์ที่อยู่กับที่ห่างจากหน้าโรเตอร์
ที่หมุน 0.5 mm

## การออกแบบ

- โมดูล Python ล้วนใหม่ `src/formula_ultimate/hierarchy/ground_contacts.py` มี
  `add_ground_contacts(layer, seed, catalogue, config)` ที่ขยาย `MechanismLayer`
  (ผลของ `plan_mechanisms` ของ Work 160 ไม่เปลี่ยน การทดสอบที่ป้องกันไว้จึงยังผ่าน)
  และ `ground_contact_problems(layer)` ที่ตรวจกฎซ้ำจากจุดยอดของโปรแกรม
- แนวมุมที่ `x = core_x0 - 0.06` และ `x = core_x1 + 0.06` ทั้งสองด้าน y ของแผ่นพื้น
  แต่ละมุมเป็น assembly ระดับราก `m<k>-ground_propulsion_braking` ติดแท็ก
  `[ground_propulsion, braking]` มีแท่งปริซึม `func-leaf-mechanism-v2` สี่ชิ้นที่
  extrude ออกด้านนอกตามแกน y:
  - เพลา: รูป N_a เหลี่ยมปกติ (หน้าแบนอยู่ด้านบน) ฝาวางบนหน้าข้างของแผ่นพื้นที่กลาง
    ความหนา รัศมีวงล้อมรอบ `r_a <= t/2 - 2 mm`; `bonded` กับแผ่นพื้น
  - สเตเตอร์: แผ่นห้าเหลี่ยมวางบนหน้าแบนด้านบนของเพลา (`bonded`) ในชั้น y ถัดจาก
    แผ่นพื้น ห่างจากหน้าโรเตอร์ 0.5 mm
  - โรเตอร์: จาน N_r เหลี่ยมมีรูเจาะ N_a เหลี่ยม `bonded` กับล้อ
  - ล้อ: จาน N_w เหลี่ยม (N_w เป็นเลขคู่ มีจุดยอดหนึ่งชี้ลงตรง) มีรูเจาะแบบเดียวกัน
    interface `bearing` กับเพลา
- รูเจาะ: N_a เหลี่ยม apothem `r_a + c` (c = 2.5e-5 m) ที่เวกเตอร์ตั้งฉากของหน้าชี้ไป
  ที่จุดยอดของเพลา ระยะห่างสถิตจึงเป็น c และไม่มีการหมุนใดทำให้เพลาชนผนังรู
- การเคลื่อนที่ต่อมุม `{wheel, rotor}` แบบ revolute รอบแกนเพลา ช่วง 2 pi
- รัศมีล้อสุ่มต่อคันโดย `R > t/2 + 1 mm + ระยะเผื่อ` เพื่อให้จุดยอดล่างของล้อเป็นจุด
  ต่ำสุดของทั้งคัน และผิวล่างแผ่นพื้น โรเตอร์ เพลา สเตเตอร์ อยู่เหนือแถบพื้น 1 mm
- หลักฐาน: `ground_propulsion: {motions: [4 ids]}`,
  `braking: {rotor_motion: <การเคลื่อนที่ของมุมแรก>, stator: <สเตเตอร์ของมุมนั้น>}`
- ตัวสร้างเรียก `add_ground_contacts` หลัง `plan_mechanisms` และนำ config ของจุด
  สัมผัสพื้นเข้า `config_sha256`

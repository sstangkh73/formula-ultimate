วันที่: 2026-09-28 (Asia/Bangkok)

Status: Completed

## วัตถุประสงค์

อ่าน PDF ทุกไฟล์ที่มีอยู่ใน `papers/` จัดทำรายงานที่ตรวจสอบย้อนกลับถึงหลักฐานได้สำหรับ paper แต่ละฉบับ และจัดทำรายงานสังเคราะห์ข้าม paper แยกตามหัวข้อของคลัง โดยต้องระบุว่าเอกสารพบอะไร อะไรน่าสนใจ เชื่อมกับ Formula Ultimate อย่างไร และควรนำไปปรับปรุงส่วนใดของโครงการอย่างเป็นรูปธรรม

## ขอบเขต

1. ทำบัญชี PDF ในเครื่องทุกไฟล์ พร้อมหมวด รหัส ชื่อเรื่อง จำนวนหน้า และสถานะการสกัดข้อความ
2. อ่านข้อความที่สกัดได้ทั้งหมดของ PDF ทุกฉบับ รวมวิธีการ ผลลัพธ์ ข้อจำกัด และข้อสรุป ไม่ใช้เพียงชื่อเรื่องหรือบทคัดย่อ
3. สร้างคู่รายงาน Markdown ภาษาอังกฤษและภาษาไทยแยกสำหรับ paper ทุกฉบับ
4. สร้างคู่รายงานรวมสองภาษา แบ่งตามหมวดของคลัง พร้อมธีมร่วม ความเห็นที่ขัดกัน ช่องว่างหลักฐาน และลำดับการปรับปรุงโครงการ
5. ตรวจข้อเสนอการปรับปรุงกับสถาปัตยกรรม ขอบเขตการยืนยันผล และเอกสารวิจัยปัจจุบันของ Formula Ultimate
6. เพิ่มเครื่องมือที่ทำซ้ำได้และ metadata การอ่านแบบ machine-readable ตามความเหมาะสม โดยไม่แก้ source PDF

- แผนสองภาษานี้และบันทึกผลสองภาษาที่ตรงกัน

## การตรวจสอบ

1. บัญชี PDF และ reading manifest ต้องมีชุด PDF ในเครื่องตรงกันทุกไฟล์
2. source PDF ทุกฉบับต้องมีรายงานภาษาอังกฤษหนึ่งไฟล์และคู่ภาษาไทยหนึ่งไฟล์ โดยรายงานไทยระบุชื่อไฟล์แหล่งภาษาอังกฤษ
3. ทุก report ต้องมี bibliographic identity, คำถามวิจัย, วิธี/ข้อมูล, ผลหลัก, ข้อจำกัด, ความเชื่อมโยงกับ Formula Ultimate และการเปลี่ยนแปลงที่ลงมือทำได้ พร้อมอ้างหน้าเมื่อการสกัดรองรับ
4. รายงานรวมครอบคลุมทุกหมวดของคลังและลิงก์ไปยังรายงานทุกฉบับ
5. test ด้าน repository/document integrity ผ่าน และ script ตรวจจำนวนรายงาน source hash คู่ภาษา required sections และ internal links ผ่าน
6. `git diff --cached --check` ผ่านสำหรับชุดไฟล์ที่ stage อย่างเจาะจงของ work item นี้

## เกณฑ์สำเร็จ

- ไม่มี PDF ในเครื่องฉบับใดถูกละเว้นโดยไม่บันทึก
- รายงานรายฉบับแยกคำกล่าวของผู้เขียนออกจากการตีความของเรา และไม่สื่อว่า Level-0 ยืนยันความถูกต้องทางกายภาพของแบบ
- ข้อเสนอเชื่อมกับ module, gate, protocol หรืองานที่วางแผนไว้ของ Formula Ultimate โดยระบุชื่อ ไม่ใช่คำแนะนำทั่วไป
- รายงานรวมอธิบายทั้งหลักฐานที่สอดคล้องกัน ความขัดแย้ง และหลักฐานที่ยังขาดในแต่ละหมวด
- การตรวจสอบผ่านและ work item ที่เสร็จถูก commit แบบจำกัดขอบเขตหนึ่ง commit

## ความเสี่ยง

- คลังมีขนาดใหญ่ การสกัดและสังเคราะห์เต็มฉบับอาจพบ PDF เสีย เป็นภาพสแกน หรือเข้ารหัส ต้องบันทึกกรณีดังกล่าวอย่างชัดเจนและตรวจภาพเมื่อการสกัดไม่เพียงพอ
- สมการ ตาราง และภาพอาจเสียโครงสร้างระหว่างสกัดข้อความ หลักฐานสำคัญหรือกำกวมต้องตรวจเทียบหน้าที่ render
- รายงานอาจกล่าวเกินหลักฐานเมื่อ paper เป็นแนวคิด ใช้ simulation เท่านั้น หรือเป็น benchmark เท่านั้น แต่ละ review ต้องระบุชนิดหลักฐานและข้อจำกัดการถ่ายโอน
- ห้ามนำการเปลี่ยนแปลงอื่นที่ไม่เกี่ยวข้องใน working tree เข้า commit ของงานนี้

## สิ่งที่ไม่ทำ

- ไม่แก้โค้ด physics, geometry, optimizer, controller หรือ experiment ใน work item นี้
- ไม่อ้างว่าการค้นวรรณกรรมครบถ้วนเกินชุด PDF ที่มีอยู่ใน `papers/` ขณะนี้
- ไม่เผยแพร่ซ้ำ ไม่แก้ และไม่ commit source PDF
- ไม่อ้าง physical validation จาก simulation หรือการเทียบเคียงวรรณกรรมเพียงอย่างเดียว

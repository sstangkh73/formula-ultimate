# แผน Work 084: Energy Conversion and Torque-Path Candidate 001

ไฟล์ต้นฉบับภาษาอังกฤษ: `2026-09-03_084_energy-torque-path-candidate-001-plan.md`

## สถานะ

สถานะ: Partial

## วัตถุประสงค์

แทนที่กล่อง energy converter เชิงนามธรรมและอัตราทดแบบสเกลาร์ ด้วย candidate หลายชิ้นหนึ่งแบบที่ตรวจสอบและ replay ได้ ซึ่งนำพลังงานหลักที่บรรทุกมาก่อนตามที่ประกาศ ผ่าน converter ผ่านการแปลงแรงบิดที่เกิดจากรูปทรงจริง ผ่านฐานรองรับแรงปฏิกิริยา และผ่าน housing ที่มีอินเทอร์เฟซระบายความร้อนและหล่อลื่น เข้าสู่อินเทอร์เฟซแรงบิดของ Work 083 ที่ตรึงไว้

Candidate ประกาศเทคโนโลยีพลังงานแบบเฉพาะเจาะจง โดยไม่ทำให้ evaluator เอนเอียงไปยัง layout ระบบขับเคลื่อนแบบดั้งเดิม เช่นเดียวกับ Work 083 งานซอฟต์แวร์และ CAD อาจเสร็จสมบูรณ์ได้ แต่คำตัดสิน design admission ต้องยังเป็นลบ เพราะหลักฐานวัสดุ กระบวนการ และการวัดที่มีอยู่เป็น `synthetic_verification`

## ขอบเขตและการทดลองที่ตรึงไว้

ตรึง candidate เจ็ดชิ้นก่อนการประเมิน:

1. `energy_store` — ภาชนะกลวงที่บรรจุพลังงานหลักก่อนการแข่งตามที่ประกาศ
2. `converter_housing` — รูเจาะ อินเทอร์เฟซยึด ครีบระบายความร้อน ช่องน้ำหล่อเย็นสองช่อง และพอร์ตป้อนสารหล่อลื่นหนึ่งพอร์ต
3. `converter_rotor` — ชิ้นหมุนขาออกของ converter ภายในรูเจาะของ housing
4. `input_shaft` — ชิ้นส่งแรงบิดฝั่ง rotor และรัศมีขับของ traction
5. `ratio_drum` — รัศมีตามของ traction และชิ้นแปลงแรงบิด
6. `output_shaft` — ชิ้นร่วมแกนที่สิ้นสุดที่อินเทอร์เฟซ axle ของ Work 083
7. `support_block` — ฐานรองรับแรงปฏิกิริยาที่มีรูแบริ่งของกลุ่มขาออก

กฎที่ตรึงไว้สำหรับงานนี้:

- ใช้ SI ใน declaration แปลงเป็นมิลลิเมตรเฉพาะที่ขอบเขต CadQuery เท่านั้น กรอบอ้างอิงคือ `+x` ไปหน้า `+y` ไปซ้าย `+z` ขึ้นบน เหมือน Work 083
- คำนวณ mobility จากต้นไม้ข้อจำกัดที่ประกาศชัดเจนเจ็ดข้อต่อ บวกแถว rolling coupling ที่ปิดวงซึ่งประกาศแยกหนึ่งแถว ผลที่ประกาศและที่คำนวณต้องเท่ากับ `1 DOF` รอบแกน `+y` พอดี
- อัตราทดคือ `driven_radius / drive_radius` ซึ่งมาจากรัศมีที่ตรึงไว้สองค่าเดียวกับที่ใช้สร้าง B-rep ไม่ใช่สเกลาร์อิสระ
- ประเมินระยะห่างและการทับซ้อนของ B-rep จริงสำหรับทุกคู่ชิ้นส่วน คู่ที่ยึดติดกันและคู่ที่เป็น coupling ถูกประกาศแยกจากคู่ต้องห้าม ห้ามกลบการทับซ้อนหรือ healing ทุกกรณี
- กราฟแรงบิดต้องมีเส้นทางต่อเนื่องหนึ่งเส้นเท่านั้นจาก `converter_rotor` ไปยัง `contact_roller` ของ Work 083 โดยผ่าน node `axle` ของ Work 083 และขา Work 083 ต้องผูกกับแฮชผลลัพธ์และแฮช assembly ของ Work 083 ที่ตรึงไว้
- กราฟแรงปฏิกิริยาต้องมีเส้นทางต่อเนื่องหนึ่งเส้นเท่านั้นจาก `converter_housing` ไปยังปลายทางโครงสร้างที่ประกาศ
- บัญชีพลังงานบังคับพลังงานหลักที่บรรทุกมาก่อนการแข่ง การไหลเข้าของพลังงานหลักจากภายนอกเท่ากับศูนย์ ประสิทธิภาพอยู่ใน `[0,1]` และแหล่งพลังงานที่กู้คืนต้องสืบย้อนไปยังแหล่งเบรกที่อนุรักษ์ตามที่ประกาศ
- บัญชีความร้อนใช้มวล housing ที่ได้จากรูปทรง พื้นที่พาความร้อนที่ครีบเพิ่มขึ้นซึ่งได้จากรูปทรง และพื้นที่หน้าตัดช่องน้ำหล่อเย็นที่ได้จากรูปทรง ความเร็วน้ำหล่อเย็น อุณหภูมิที่เพิ่มขึ้นของน้ำหล่อเย็น และอุณหภูมิ housing ต้องอยู่ในโดเมนที่ประกาศโดยไม่มีการตัดค่า
- ขอบเขตความปลอดภัยเชิงโครงสร้างของ `output_shaft`, `support_block` และ `converter_housing` เป็นเชิงวิเคราะห์และได้จากรูปทรง มีป้ายกำกับ `analytic_synthetic_verification` และไม่ใช่การแก้ปัญหาด้วยเมช

ตัวแปรอิสระคือเทคโนโลยีที่ประกาศ topology รัศมี traction หน้าตัดเพลาและฐานรองรับ ระยะห่างฐานรองรับ ตารางความเร็วและแรงบิด ประสิทธิภาพ converter และกลไก ประสิทธิภาพการกู้คืน การประกาศน้ำหล่อเย็น รูปทรง housing สถานะการเชื่อมต่อ และสถานะกระจก ตัวแปรตามคืออัตลักษณ์ชิ้นส่วน mobility อัตราทด ระยะห่าง แรงบิดที่ส่งผ่าน wrench ปฏิกิริยา กำลังที่ส่งมอบ เศษเหลือพลังงานและความร้อน ความเร็วและอุณหภูมิน้ำหล่อเย็น อุณหภูมิ housing ขอบเขตโครงสร้างเชิงวิเคราะห์ สถานะระบบย่อย การตอบสนองของ control และอัตลักษณ์ replay

Candidate อ้างอิงและกระจกที่ตรึงไว้เป็น control เชิงบวก ส่วนความบกพร่องที่ฉีดเข้าไปทุกอันเป็น falsification control

## Control ที่ประกาศ

`mirror`, `locked_converter`, `seized_support`, `broken_coupling`, `zero_loss_exploit`, `efficiency_over_one`, `reversed_torque`, `overspeed`, `inadequate_cooling` และ `disconnected_housing_reaction` แต่ละอันต้องให้ผลที่วัดได้ตามที่ลงทะเบียนล่วงหน้า control ที่หายไปหรือไม่มีผลทำให้การประเมินล้มเหลว

## เกณฑ์ความสำเร็จ

- มีชิ้นส่วน solid ที่ถูกต้องแยกกันเจ็ดชิ้น และมี STEP กับ FCStd ของ assembly ที่มีเจ็ด solid
- mobility ที่คำนวณได้เท่ากับ `1 DOF` พอดี และอัตราทดที่คำนวณได้เท่ากับ `driven_radius / drive_radius` พอดี
- เส้นทางแรงบิดเส้นเดียวไปถึงชิ้นสัมผัสของ Work 083 ที่ตรึงไว้ และเส้นทางปฏิกิริยาเส้นเดียวไปถึงปลายทางโครงสร้างที่ประกาศ
- เศษเหลือของแรงบิดและปฏิกิริยาแต่ละค่า `<=1e-5` เศษเหลือพลังงานและเศษเหลือความร้อนแต่ละค่า `<=1e-4`
- ประสิทธิภาพอยู่ใน `[0,1]` การไหลเข้าของพลังงานหลักจากภายนอกเท่ากับ `0 J` พอดี พลังงานในถังสุดท้ายไม่เกินพลังงานเริ่มต้น และพลังงานที่กู้คืนสืบย้อนไปยังแหล่งเบรกที่อนุรักษ์ตามที่ประกาศพร้อมบันทึกการสูญเสีย
- ความเร็วน้ำหล่อเย็น อุณหภูมิที่เพิ่มขึ้นของน้ำหล่อเย็น และอุณหภูมิ housing อยู่ในโดเมนที่ประกาศ และอุณหภูมิ housing ที่เพิ่มขึ้นได้มาจากปริมาตร housing ของ CadQuery ไม่ใช่ค่าคงที่ที่พิมพ์เข้าไป
- ทุก control ที่ประกาศให้ผลที่วัดได้ตามที่ลงทะเบียนล่วงหน้า
- การรันสองครั้งสร้างอัตลักษณ์ canonical ทุกค่าซ้ำได้พอดี
- คำตัดสิน candidate เป็น `not_admitted_synthetic_evidence`

## Gate ที่งานนี้ไม่ปิด

Completion gate ของ Work 084 ใน `WORKS_080_086_DETAILED_EXECUTION_PLAN.md` กำหนดว่ากรณีโครงสร้างของเพลา ฐานรองรับ และ housing ต้องผ่าน gate ของ Work 082 หรือล้มเหลวอย่างสังเกตได้ แต่ evaluator ของ Work 082 จับคู่บริเวณรับแรงเป็นรูทรงกระบอกแกน `z` และจับคู่ฐานรองรับเป็นระนาบ `x` คงที่ จึงไม่สามารถรับรูแกน `y` การรับแรงบิดบิด หรือแรงปฏิกิริยาแบริ่งของ candidate นี้ได้ หากไม่เปลี่ยนอัตลักษณ์ configuration ของ Work 082 ที่ตรึงไว้ กฎโปรแกรมข้อ 4.1 ห้ามการเปลี่ยนแปลงนั้น และ `WORK_PROTOCOL.md` ห้ามการขยายขอบเขตงานปัจจุบันแบบเงียบ ๆ

ดังนั้น Work 084 จึงส่งมอบขอบเขตความปลอดภัยเชิงวิเคราะห์สำหรับแรงบิดบิด แบริ่ง และ housing ที่ได้จากรูปทรง และบันทึกว่า gate โครงสร้างแบบเมช **ไม่ผ่าน** หากการตรวจสอบที่ประกาศไว้ส่วนอื่นผ่าน งานนี้จะปิดด้วยสถานะ `Partial` ไม่ใช่ `Completed` และต้องมีงานแก้ไขที่มีหมายเลขแยกต่างหากเพิ่มเส้นทางเมชสำหรับแรงบิดบิด แบริ่ง และ housing ก่อนจะอ้าง Gate B หรือ Work 085 ได้

## ความเสี่ยงและการควบคุม

- รัศมีตามที่ใหญ่เกินไปอาจทำให้ drum อยู่ต่ำกว่าระนาบสัมผัสของ Work 083 การควบคุม: ตรึง `driven_radius_m` ให้ต่ำกว่ารัศมี roller ของ Work 083 และรายงานระยะห่างจากพื้นที่วัดได้เป็นหลักฐาน
- ทรงกระบอก traction ที่สัมผัสกันพอดีทำให้การตัดกันของ B-rep เปราะเชิงตัวเลข การควบคุม: ประกาศช่องว่างการขบเชิงรัศมีที่จำกัด ถือคู่ traction เป็นคู่ coupling ไม่ใช่คู่ต้องห้าม และระบุว่าชิ้นส่วนการขบไม่ได้ถูกจำลอง
- การต่อกับ Work 083 เป็นอินเทอร์เฟซชนหน้าร่วมแกนที่ไม่มีตัวยึดที่จำลองไว้ การควบคุม: ตรวจความร่วมแกน รัศมี และความบรรจบของระนาบปลายจากรูปทรง และบันทึกตัวยึดที่ขาดหายเป็นข้อจำกัด ไม่ใช่ข้อต่อที่ผ่านการตรวจสอบ
- บัญชีที่จับคู่กันเชิงพีชคณิตอาจให้เศษเหลือใกล้ศูนย์โดยไม่มีเนื้อหาทางกายภาพ การควบคุม: คำนวณการระบายความร้อนจากการประกาศน้ำหล่อเย็นและรูปทรง housing แบบอิสระ เพื่อให้การปิดบัญชีเป็นการตรวจสอบไม่ใช่เอกลักษณ์ และบันทึกความเป็นวงกลมที่ยังเหลืออยู่
- คอนเทนเนอร์ STEP และ FCStd อาจมี metadata ที่ผันแปร การควบคุม: ทำ timestamp ของ STEP ให้เป็น canonical และใช้เฉพาะรายงาน FreeCAD แบบ canonical เป็นหลักฐาน replay ของ FCStd

## เป้าหมายที่ไม่ทำอย่างชัดเจน

- ไม่อ้างว่ามอเตอร์ เครื่องยนต์ แบตเตอรี่ เชื้อเพลิง ระบบส่งกำลัง คลัตช์ แบริ่ง คัปปลิง ระบบหล่อลื่น หรือระบบระบายความร้อน ผ่านการตรวจสอบแล้ว
- ไม่อ้างความเหนือกว่าของเทคโนโลยี ความสมจริงของประสิทธิภาพ ความพร้อมการผลิต ความปลอดภัย อายุความล้า หรือการตรวจสอบทางกายภาพ
- ไม่มีการแก้ปัญหาโครงสร้างด้วยเมชสำหรับเพลา ฐานรองรับ หรือ housing
- ไม่จำลองการลดลงของความเร็วระหว่างช่วงเบรก
- ไม่แก้ปัญหาการจัดวาง เส้นทางบำรุงรักษา หรือการทับซ้อนระดับรถทั้งคัน ซึ่งเป็นงานของ Work 085
- ไม่มีการซ่อมแอบแฝง การตัดค่าแรงหรืออุณหภูมิ การกลบการทับซ้อน การกลายพันธุ์รูปทรงที่ขึ้นกับผลลัพธ์ หรือการเปลี่ยนป้ายหลักฐาน synthetic เป็น design
- ไม่มีโครงสร้างรับภาระแบบบูรณาการของ Work 085 และไม่มีรถทั้งคันของ Work 086

## แนวทาง

ทุก package ระบุวัตถุประสงค์ เงื่อนไขเริ่ม source inputs ไฟล์ที่เสนอ ขั้นพัฒนาตามลำดับ ตัวแปร/ตัวควบคุม tests และ negative controls เฉพาะทาง ช่องตัวเลขที่ต้องลงทะเบียน เกณฑ์ผ่าน/ไม่ผ่าน ผลหลักฐาน ความเสี่ยง สิ่งที่ไม่ทำ และงานรับต่อ รักษาเสรีภาพรูปทรงไม่คุ้นเคย ฮาร์ดแวร์ภายในจริง หลักฐานหลายสเกล บัญชีต้นทุนเป็นธรรม และ exploratory integration ตั้งแต่ต้น แยกเอกสารเสร็จจากวิศวกรรมสำเร็จและสมมติฐานวิทยาศาสตร์เป็นจริง

## วัตถุประสงค์

ค้นหา paper ที่เกี่ยวข้องกับ Formula Ultimate ทั้งทางตรง (วัตถุประสงค์หรือวิธีแบบเดียวกัน) และทางอ้อม (วิธี ชุดข้อมูล หรือผลการวัดที่โครงการนำมาใช้ได้) โดยไม่กำหนดจำนวนสูงสุด ดาวน์โหลดทุก paper ที่มีสำเนา open access ที่ถูกต้องตามกฎหมายเก็บในโฟลเดอร์แยกภายในโปรเจกต์ และบันทึกสำหรับทุก paper ที่พบว่าสำคัญอย่างไร และมีสำเนาในเครื่องหรือไม่

## ขอบเขต

1. รายการแหล่งที่คัดสรรครอบคลุมหัวข้อที่โครงการทำจริง: การออกแบบอัตโนมัติและ open-ended, การออกแบบรูปร่างร่วมกับตัวควบคุม, quality diversity และการค้นหาแบบ multifidelity, การสร้าง CAD/B-rep/การประกอบ, topology optimization, meshing และ contact, optimal control เวลาต่อรอบต่ำสุดและการออกแบบร่วมกับการควบคุม, การจัดการพลังงานในการแข่ง, ยาง, อากาศพลศาสตร์และชุดข้อมูล aero, แหล่งเก็บพลังงานและระบบส่งกำลัง, ความร้อนและการระบายความร้อน, วัสดุ, ความล้า, ข้อต่อและพิกัดความเผื่อ, verification/validation/UQ, สถิติและการทำซ้ำได้, specification gaming และข้อมูลการแข่งรถอัตโนมัติ
2. รวม P01–P62 เดิมไว้ด้วยเพื่อให้คลังครบในที่เดียว
3. ตัว resolver/downloader ที่ยืนยันตัวตนของแต่ละ paper กับ metadata ของ arXiv หรือ OpenAlex ก่อนรับไฟล์ ดาวน์โหลดจากตำแหน่ง open access ที่ resolve ได้เท่านั้น ตรวจว่าเป็น PDF และบันทึก SHA-256 ขนาด URL และสถานะ
4. แค็ตตาล็อกสองภาษาที่อ่านได้ สร้างจากรายการแหล่งชุดเดียวกัน

## ไฟล์ที่วางแผนไว้

- `docs/research/paper_library/sources_v1.json` — รายการคัดสรร: id, หมวด, ชื่อเรื่อง, ผู้แต่ง, ปี, แหล่งตีพิมพ์, ตัวระบุ, ความสัมพันธ์ (ตรง/อ้อม/ข้อมูล), หมายเหตุความเกี่ยวข้องภาษาอังกฤษและไทย
- `docs/research/paper_library/manifest_v1.json` — สร้างอัตโนมัติ: ตัวตนที่ resolve ได้, URL ดาวน์โหลด, SHA-256, จำนวนไบต์, path ในเครื่อง, สถานะ
- `docs/research/paper_library/PAPER_LIBRARY_2026-09-27.md` และ `.th.md` — แค็ตตาล็อกที่สร้างอัตโนมัติ
- `scripts/research/build_paper_library.py` — resolver, downloader และตัวสร้างแค็ตตาล็อก
- `tests/test_paper_library.py` — ความถูกต้องของแค็ตตาล็อก (id ไม่ซ้ำ, ฟิลด์ที่ต้องมี, หมวด, manifest ตรงกับ sources)
- `papers/.gitignore` — ทำให้ PDF ที่ดาวน์โหลดอยู่เฉพาะในเครื่อง
- `papers/<category>/*.pdf` — อยู่ในเครื่องเท่านั้น ไม่ commit
- แผนสองภาษานี้และผลลัพธ์สองภาษาที่ตรงกัน

## การตัดสินใจเรื่องที่เก็บและลิขสิทธิ์

repository นี้ถูก push แบบสาธารณะ และเอกสารใช้สัญญาอนุญาต CC BY 4.0 paper ส่วนใหญ่ รวมถึงหลายชิ้นที่เป็น open access ไม่อนุญาตให้เผยแพร่ซ้ำภายใต้สัญญาอนุญาตนั้น PDF จึงเก็บไว้ใน `papers/` ซึ่งถูก git-ignore ด้วย `papers/.gitignore` ของตัวเอง commit เฉพาะ metadata (ชื่อเรื่อง ตัวระบุ URL hash หมายเหตุ) ไม่แตะ `.gitignore` ที่ root ซึ่งมีการแก้ของผู้ใช้ที่ยังไม่ commit

## การตรวจสอบ

1. `python scripts/research/build_paper_library.py --download` ทำงานจบ ทุกรายการจบด้วยสถานะที่บันทึกไว้ (`downloaded`, `no_open_access_copy`, `identity_unconfirmed` หรือ `download_failed`) ไม่มีรายการใดหายไปอย่างเงียบ ๆ
2. ทุกไฟล์ที่ `downloaded` ขึ้นต้นด้วย `%PDF`, SHA-256 ตรงกับ manifest และชื่อเรื่องที่ resolve ได้ตรงกับชื่อเรื่องที่คัดสรร
3. `python -m unittest tests.test_paper_library tests.test_repository_contract`: exit 0
4. `git status --short papers` ไม่แสดง PDF; `git diff --cached --check`: exit 0

## เกณฑ์สำเร็จและล้มเหลว

สำเร็จ: แค็ตตาล็อกใหญ่กว่า 62 paper ของ Work 102 อย่างมีนัยสำคัญ ครอบคลุมทุกหัวข้อในขอบเขต ทุก paper ในแค็ตตาล็อกมี PDF ในเครื่องที่ตรวจแล้ว หรือมีเหตุผลชัดเจนว่าทำไมไม่มี และไม่มี PDF ถูก stage

ล้มเหลว: ไฟล์ถูกบันทึกภายใต้ชื่อ paper ผิดเรื่อง (ไม่ได้ตรวจตัวตน), ดาวน์โหลดจาก mirror ที่ผิดกฎหมาย, PDF ถูก commit หรืออ้างว่าดาวน์โหลดแล้วโดยไม่มี hash

## ความเสี่ยง

- arXiv identifier หรือ DOI ที่จำมาอาจผิด การลดความเสี่ยง: ยืนยันตัวตนกับ metadata ของ resolver ด้วยความคล้ายของชื่อเรื่อง หากไม่ตรงจะบันทึกไว้ ไม่บันทึกไฟล์ภายใต้ชื่อที่คัดสรร
- PDF ของสำนักพิมพ์บางแห่งอยู่หลังการตรวจ bot รายการเหล่านั้นจะบันทึกเป็น `download_failed` หรือ `no_open_access_copy` พร้อมลิงก์หน้าเว็บ ไม่ข้าม CAPTCHA หรือการควบคุมการเข้าถึงใด ๆ
- การค้นงานที่เกี่ยวข้องไม่มีทางครบถ้วน ผลลัพธ์จะระบุเช่นนั้น
- หมายเหตุความเกี่ยวข้องเป็นการประเมินจากบทคัดย่อและเนื้อหาที่ทราบ ไม่ใช่การอ่านทุก paper เต็มฉบับ

## สิ่งที่ไม่ทำ

- ไม่ใช้ sci-hub หรือ mirror ที่ไม่มีสิทธิ์ ไม่ดาวน์โหลดสิ่งที่ต้องจ่ายเงิน
- ไม่แก้โค้ดฟิสิกส์ configuration gate หรือ claim
- ไม่ประเมินแค็ตตาล็อกของ Work 102 ใหม่ P01–P62 คงรายการของตัวเอง และคลังใหม่อ้างถึงด้วยหมายเลข P
- ไม่อ้างว่าโครงการเป็นงานใหม่เพียงเพราะการค้นไม่พบคู่แข่ง

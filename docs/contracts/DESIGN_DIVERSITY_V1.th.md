# Contract ความหลากหลายในการออกแบบ V1

ไฟล์ต้นฉบับภาษาอังกฤษ: `DESIGN_DIVERSITY_V1.md`

`design_diversity_v1` วัดโอกาสของ representation ไม่ได้ประกาศ novelty หรือคุณค่าทางฟิสิกส์ Topology signature ไม่ขึ้นกับชื่อ component/interface และ rigid/global scale transform ส่วน geometry signature บันทึก primitive family, normalized dimension, normalized interface radius และระยะระหว่าง component เพิ่ม Absolute characteristic length ยังคงเป็นปริมาณฟิสิกส์แยกต่างหาก

Census Work 090 ถูกตรึงกับ opportunity ledger exact ของ Work 050: `GRID`, `RANDOM`, `EVOLUTION`; seed `101/202/303`; และ `32` attempt ต่อ treatment/seed รวม `288` proposal Census รายงาน signature coverage, duplicate, primitive/type/curvature metric, functional path signature และ outcome failure ที่จำกัดของ Work 050

Translation, signed axis permutation, renaming และ uniform scale เป็น control ที่ไม่ใหม่ ส่วน branch addition, connectivity reroute, primitive-family change และ interface-topology change ต้องถูกตรวจพบ Reference หาย, geometry non-finite, source identity เปลี่ยน หรือ field ไม่ได้ประกาศต้อง fail closed

V1 ใช้ graph refinement แบบ Weisfeiler-Lehman ที่มีขอบเขตและ invariant จาก radial/distance Rare graph-hash collision และการสูญเสีย chirality เป็นข้อจำกัดที่ทราบ งาน free-form ภายหลังต้องขยาย descriptor แทนการใช้ measurement contract นี้เป็น physical evaluator

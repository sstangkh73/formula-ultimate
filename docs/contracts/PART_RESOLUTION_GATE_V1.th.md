# Gate ความละเอียดของชิ้นส่วนและระบบข้อต่อ v1

แหล่งภาษาอังกฤษ: `PART_RESOLUTION_GATE_V1.md`

Protocol version: `part_resolution_gate_v1` implement โดย Work 140

## 1. ขอบเขตของสัญญานี้

ตอบสองคำถามที่โปรเจกต์ยังตอบเกี่ยวกับ geometry ของตัวเองไม่ได้ คือชิ้นส่วนถูกโมเดลที่ระดับความละเอียดของชิ้นส่วนจริงหรือไม่ และข้อต่อที่ประกาศเป็นผิวต่อจริงหรือไม่ ทั้งสองคำตอบมาจากการวัด solid ที่สร้างจริง ไม่ใช่จากคำประกาศ

```text
คำประกาศชิ้นส่วน (ไฟล์ STEP หรือ reference build)
  -> CadQuery สร้างและวัด: หน้า ขอบ ชนิดผิว ขอบสั้นสุด ขอบที่เปอร์เซ็นไทล์ที่สิบ ปริมาตร กรอบขอบเขต
  -> Gmsh สร้าง mesh ที่ size factor ที่ลงทะเบียน
  -> gate ความละเอียด -> สถานะที่ลงทะเบียนหนึ่งค่าต่อชิ้น

คำประกาศข้อต่อ (เทคโนโลยี สองชิ้นส่วน การวางตำแหน่ง ช่วงระยะสวม)
  -> วัดระยะใกล้สุด ปริมาตรแทรกสอด ความลึกการกดทับ คู่ผิวสัมผัส พื้นที่ซ้อนทับ ผิวขบ
  -> ตรวจหลักฐานตามเทคโนโลยี -> สถานะที่ลงทะเบียนหนึ่งค่าต่อข้อต่อ
```

## 2. ตัวชี้วัด feature สองตัว คนละหน้าที่

- `smallest_feature_m` คือขอบสั้นสุดที่ชิ้นส่วนมี ใช้ตอบว่าชิ้นส่วนมีเศษบางเฉียบหรือไม่ โดยเทียบกับ `minimum_feature_m`
- `feature_scale_m` คือความยาวขอบที่เปอร์เซ็นไทล์ที่สิบ ใช้ตอบว่าชิ้นส่วนถูกโมเดลที่สเกลใด และเป็นค่าที่ mesh ต้องแบ่งผ่านให้ได้

ถ้าใช้ขอบสั้นสุดทำทั้งสองหน้าที่ ขอบเล็กเพียงเส้นเดียวจะบังคับให้ต้องใช้ mesh ที่แพงเกินจำเป็นกับชิ้นส่วนที่จริง ๆ แล้วหยาบ

## 3. สถานะของชิ้นส่วน

| สถานะ | ความหมาย |
| --- | --- |
| `passed_resolution` | อยู่เหนือพื้นความเป็นไปได้ในการผลิต ผ่านข้อกำหนดของชั้นตัวเอง และ mesh แบ่งผ่านสเกล feature ได้ |
| `insufficient_resolution` | ต่ำกว่าข้อกำหนดเรื่องจำนวนหน้า หน้าโค้ง ขอบ หรือจำนวนสเกลของชั้นตัวเอง |
| `unmanufacturable_feature` | ขอบสั้นสุดต่ำกว่าพื้นที่ลงทะเบียน เศษบางเฉียบไม่ใช่ความละเอียด |
| `unresolved_measurement` | ไม่มีการวัด ไม่มี mesh หรือ mesh หยาบเกินกว่าจะแบ่งผ่านสเกล feature |

คำตัดสินเชิง geometry มาก่อนคำตัดสินเรื่อง mesh เสมอ เพราะการที่ชิ้นส่วนถูกโมเดลหยาบไม่ได้ขึ้นกับว่าตัว mesh ทำงานสำเร็จหรือไม่ และความล้มเหลวของ mesh ยังถูกบันทึกไว้ในฟิลด์ `mesh_failure` ของชิ้นนั้น

## 4. เทคโนโลยีข้อต่อและหลักฐานที่ต้องมี

แบบจะยึดชิ้นส่วนด้วยวิธีใดก็ได้ gate นี้ไม่เคยบังคับให้ใช้ตัวยึด แต่บังคับว่าเทคโนโลยีที่ประกาศต้องมีการวัดรองรับ

| เทคโนโลยี | หลักฐานที่ต้องวัดได้ |
| --- | --- |
| `threaded` | `engagement_faces` (ผิวที่ไม่ใช่ระนาบและไม่ใช่ทรงกระบอกอย่างน้อยสองหน้ารวมทั้งคู่), `bearing_face` (คู่ผิวสัมผัสอย่างน้อยหนึ่งคู่), `clearance_in_range` |
| `welded` | `added_fillet_material` (ปริมาตรแทรกสอดมากกว่าศูนย์), `continuous_interface` |
| `bonded` | `bond_line_in_range`, `overlap_area` ไม่น้อยกว่าค่าต่ำสุดที่ประกาศ |
| `interference` | `interference_in_range` วัดเป็นระยะสวมติดลบจากความลึกการกดทับ `2V/A` ของ solid ที่ตัดกัน |
| `integral` | `single_continuous_solid` |

| สถานะ | ความหมาย |
| --- | --- |
| `passed_joint_evidence` | วัดหลักฐานที่ต้องมีได้ครบทุกข้อ |
| `out_of_range_fit` | มีเพียงข้อกำหนดเรื่องระยะสวมที่ไม่ผ่าน ผิวต่อยังมีอยู่จริง |
| `unsupported_joint_evidence` | ชิ้นส่วนไม่มี geometry ที่จำเป็นอยู่จริง |
| `unresolved_joint_measurement` | kernel ปฏิเสธ หรือมีชิ้นส่วนที่ยังไม่ได้วัด |

## 5. ขอบเขตข้ออ้าง

`passed_part_resolution_gate` หมายถึง gate ทำงาน ทุกหัวข้อมีสถานะที่ลงทะเบียนหนึ่งค่า และ control ทั้งแปดถูกปฏิเสธ หัวข้อที่ไม่ผ่านคือข้อค้นพบเกี่ยวกับหัวข้อนั้น ไม่ใช่ความล้มเหลวของการรัน และต้องรายงานแทนการลดมาตรฐาน

protocol นี้ไม่ได้แก้สมการแรงข้ามข้อต่อใด ๆ คู่ผิวสัมผัส ระยะสวม และการแทรกสอดที่วัดได้เป็นหลักฐานของผิวต่อเท่านั้น ผลลัพธ์ระบุ `discovery_claim`, `promotion_allowed`, `race_time_claim` และ `physical_validation` เป็นเท็จ

## 6. Control ที่บังคับ

`sliver_below_manufacturing_floor`, `primitive_below_resolution_requirement`, `mesh_too_coarse_for_feature`, `joint_without_measurable_interface`, `fit_outside_declared_range`, `technology_outside_registry`, `no_discovery_claim` และ `exact_replay` ทั้งแปดข้อต้องถูกปฏิเสธ และการ replay บน tree ที่สะอาดต้องให้ result SHA-256 ตรงกันทุกประการ

control เรื่อง mesh เลือกหัวข้อที่ผ่าน gate เชิง geometry แล้ว เพราะไม่เช่นนั้นการตกเรื่องความละเอียดจะบังสิ่งที่ control ต้องการทดสอบ

## 7. วินัยของการลงทะเบียน

mesh size factor, พื้นความเป็นไปได้ในการผลิต, จำนวน element ที่ต้องพาด feature และข้อกำหนดของทุกชั้นชิ้นส่วน ถูก freeze ไว้ใน `config/development/part_resolution_gate_v1.json` ก่อนการรัน admitted การรัน pilot ใช้กำหนดค่าเหล่านั้นได้ แต่การเปลี่ยนค่าหลังเห็นผล admitted คือการซ่อมหลังสังเกตและเป็นสิ่งต้องห้าม

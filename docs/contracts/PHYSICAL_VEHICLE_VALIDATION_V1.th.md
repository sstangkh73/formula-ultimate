# Physical Vehicle Validation V1

แหล่งภาษาอังกฤษ: `PHYSICAL_VEHICLE_VALIDATION_V1.md`

สถานะ: สร้าง offline program gate ใน Work 133; หยุด vehicle execution

Whole-vehicle stage entry ต้องมี digital, manufacturing, connection และ subsystem prerequisites ที่ valid พร้อม qualified vehicle safety review, facility authorization, authorized test director, exact configuration, measurement/incident plans และ measured telemetry Runner ไม่ควบคุมยานพาหนะ

Offline audit ปฏิเสธ unapproved stage expansion, hardware/control changes, failure หรือ incident ที่ซ่อน, energy records ที่ไม่ครบ/ไม่อนุรักษ์ และ extrapolation เกิน tested stages การที่ยานพาหนะเคลื่อนที่อย่างเดียวยืนยัน safety หรือ promotion ไม่ได้

Work 128–130 ไม่รองรับ promotion/manufacturing readiness, Work 131–132 ไม่มี measured evidence และไม่มี vehicle authorization หรือ telemetry Exact replay ยืนยันเฉพาะ stopped entry decision นี้ ไม่มีการยืนยัน physical vehicle scope, road use, safety certification หรือ guaranteed superiority

# Design Diversity Contract V1

Thai companion: `DESIGN_DIVERSITY_V1.th.md`

`design_diversity_v1` measures representational opportunity; it does not declare novelty or physical merit. Topology signatures ignore component/interface names and rigid/global scale transforms. Geometry signatures additionally record primitive family, normalized dimensions, normalized interface radii, and inter-component distances. Absolute characteristic length remains a separate physical quantity.

The Work 090 census is frozen to the exact Work 050 opportunity ledger: `GRID`, `RANDOM`, and `EVOLUTION`; seeds `101/202/303`; and `32` attempts per treatment/seed, for `288` proposals. The census reports signature coverage, duplicates, primitive/type/curvature metrics, functional path signatures, and the limited Work 050 failure outcomes.

Translation, signed axis permutation, renaming, and uniform scale are non-novel controls. Branch addition, connectivity reroute, primitive-family change, and interface-topology change must be detected. Any missing reference, non-finite geometry, changed source identity, or undeclared field fails closed.

V1 uses bounded Weisfeiler-Lehman-style graph refinement and radial/distance geometry invariants. Rare graph-hash collisions and chirality loss are known limitations; later free-form work must extend the descriptor rather than use this measurement contract as a physical evaluator.

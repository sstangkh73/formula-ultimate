Thai companion: `INDEPENDENT_CLAIM_VALIDATION_V1.th.md`

Status: Implemented by Work 129 as an independent-code-path numerical claim gate.

## Evidence boundary

Critical paired-time, source-energy, thermal-margin and structural-margin claims are recomputed from locked raw telemetry by a declared backend and source module distinct from the upstream summary implementation. A shared-function wrapper cannot qualify as independent. Candidate, telemetry and dependency identities are pinned before calculation, and upstream conclusions are compared only after the independent result exists.

The stronger interpretation applies a preregistered conservative boundary penalty and classifies disagreement against a frozen trigger. A known omitted-boundary injection must be detected. Shared assumptions and common-mode uncertainty remain explicit; a separate code path is not institutional independence.

Selected claims survive only when the independently computed effect reaches its registered threshold without an unresolved discrepancy. Exact replay requires the same result SHA-256. This contract cannot replace measured boundary histories, manufacturing evidence, physical tests, external novelty review or promotion evidence.

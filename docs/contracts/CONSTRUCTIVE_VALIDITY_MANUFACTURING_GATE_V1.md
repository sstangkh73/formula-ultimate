# Constructive Validity and Manufacturing Gate V1

Thai companion: `CONSTRUCTIVE_VALIDITY_MANUFACTURING_GATE_V1.th.md`

## Evidence boundary

This gate checks deterministic synthetic witness fixtures against declared constructive and process-envelope rules. Source candidate IDs and STEP SHA-256 identities are real prior evidence, but wall, ligament, radius, feature, access, overhang, void, tolerance, and joining values in this pilot are matched synthetic controls. Passing proves gate behavior only; it is not a measured manufacturability conclusion for any source STEP, supplier, toolchain, or material.

## Ordered operation

The gate validates exact schemas, finite SI values, source identities, process profiles, material compatibility, and equal opportunity. It then applies only preregistered repairs before performance observation. Each repair records before/after evidence hashes and changes the evaluated genotype/provenance identity. Hidden, unregistered, over-budget, or post-observation repair rejects.

Constructive checks cover B-rep validity, exact single-solid declaration, self-intersection, zero thickness, and sliver/minimum feature. Process checks cover wall, ligament, radius, tool access, overhang/support, enclosed void/escape, tolerance, joining access, and material/process compatibility. All applicable violation codes are returned; no failure is silently repaired.

## Fairness and replay

The primitive control and five curved/free-form families receive the same eight scenarios. Rejected opportunities remain in the denominator. Yield and every rejection cause are reported separately by family. Exact clean replay must reproduce the full ordered ledger and `result_sha256`.

## Limitations

Coarse scalar fixtures do not resolve local fields, face semantics, collision, swept motion, tool trajectories, inspection, cost, production quality, structural adequacy, or safety. Work 096 must derive richer semantics independently from geometry before these rules can screen actual candidate measurements.

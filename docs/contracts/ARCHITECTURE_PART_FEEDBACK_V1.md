# Architecture-Part Feedback V1

Thai companion: `ARCHITECTURE_PART_FEEDBACK_V1.th.md`

Status: Implemented by Work 117 as bounded Level-0 regeneration evidence.

## Evidence boundary and identities

The external connection task, race-rule identity, SI units, dependency commits/contracts, and exact Work 112, Work 114 and Work 115 result identities are immutable inputs. Assembly evidence supplies maximum contact load, maximum displacement and registered heat input to a versioned internal task. It does not rewrite the external task.

Each internal-task revision retains its parent SHA-256. A changed internal task invalidates the prior task evidence before a new candidate is generated. Candidate evidence retains task, geometry, seed, mass and reduced structural/thermal-margin identities. `measured_material` and `ground_interaction` remain unresolved, so every candidate must report `complete_feasibility: false`.

## Fair control and admission gates

Feedback and frozen-task modes use the same initial task, coefficients, seeds, iteration count and one evaluation per iteration. Passing requires changed task and geometry identities after causal feedback, explicit invalidation for every stale task, equal evaluation totals, unchanged external-task identity, deduplicated multifunctional-region mass and rejection of missing coefficients.

Mass or margin improvement is measured but is not required: this experiment tests whether feedback is traceable and causal, not whether the bounded generator is an optimizer. The structural and thermal evaluators are reduced models. The contract does not establish unrestricted topology search, complete feasibility, measured materials, ground interaction, vehicle readiness or physical validation.
